aslp_lifter_ocaml
=================

This is a pre-generated AArch64 lifter in Ocaml.

Usage
-----
The package `aslp_lifter_ocaml` provides the dune libraries:
`aslp_lifter_ocaml.pc_aarch64` and `aslp_lifter_ocaml.aarch64`.

Generating
----------
To re-generate the files, use
```bash
./generate.sh
```
You will need the `asli` command in your PATH.
